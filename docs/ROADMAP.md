# 路线图

本文档说明 ApiMonitor 的方向，不构成版本或日期承诺。

## v1.0.0（2026-08-06，已发布 GitHub；Store 首次提交进行中）

- Development / GitHubSideload / MicrosoftStore 分发渠道模型（构建时确定）
- StoreContext 更新检查（Store 版）；GitHub Releases 更新检查（侧载版）
- 首次启动引导（四步，可跳过、可重开）
- 应用运行状况检查（21 项只读非敏感诊断）
- Store 正式身份与独立构建（`JoKiy.ApiMonitor`）
- 正式版稳定性与合规收口；文档与仓库主页规范化

## 下一步（候选方向）

- Microsoft Store 首次发布完成后的公开页面与后续更新维护
- 新增余额 Provider（按需评估）
- 无障碍与多语言体验持续完善
- 本地化改进

不在计划内：云同步、遥测、开发者服务器、第三方 DLL Provider 动态加载、邮件/短信/Webhook 通知。
