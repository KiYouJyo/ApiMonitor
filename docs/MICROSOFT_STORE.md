This document is a drafting aid only. It does not modify the Microsoft Partner Center.

## Product name

- EN: ApiMonitor
- 中文：ApiMonitor

## Short description

- EN: Lightweight WinUI 3 app to check and track your own API account balances, starting with DeepSeek.
- 中文：基于 WinUI 3 的轻量桌面应用，查询并记录你自己的 API 账户余额，当前支持 DeepSeek。

## Full description

- EN: ApiMonitor lets you add API accounts, query current balances, keep local balance history, set per-currency low-balance thresholds, and refresh automatically while the app is running. API keys are stored in the Windows Credential Locker and are only sent to the provider's official balance API. No telemetry, ads, or background tasks.
- 中文：ApiMonitor 支持添加 API 账户、查询当前余额、保存本地余额历史、设置各币种低余额阈值，并在应用运行期间自动刷新。API Key 保存在 Windows 凭据管理器，仅发送给 Provider 官方余额接口；无遥测、广告和后台任务。

## Key features

- EN: Automatic refresh while running; local balance history; low-balance thresholds; secure API key storage; one-click key copy; manual refresh; DeepSeek support.
- 中文：运行期间自动刷新；本地余额历史；低余额阈值；API Key 安全存储；一键复制密钥；手动刷新；支持 DeepSeek。

## System requirements

- Windows 10 1809 (build 17763) or later; x64; Windows App Runtime 2.3.1 or later

## Privacy statement

- EN: See PRIVACY.md. Keys stay in Credential Locker; balance data stays local; no telemetry.
- 中文：参见 PRIVACY.md。密钥保存在 Credential Locker；余额数据仅存本机；无遥测。
