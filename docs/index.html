ApiMonitor

在一个原生 Windows 应用中管理多个 API 平台与账户，查看余额、额度、服务健康及历史趋势。支持 AI 与地图/GIS 服务，账户与历史留在本机，密钥保存在 Windows Credential Locker。

複数の API プラットフォームとアカウントの残高、枠、サービス健全性、履歴を Windows アプリで管理。AI・地図/GIS に対応し、データはローカル、キーは Windows Credential Locker に保存します。

Monitor multiple API platforms and accounts in one native Windows app. Track balances, credits, service health, and trends across AI and map/GIS services; data stays local and keys use Windows Credential Locker.

本地优先与隐私ローカル優先とプライバシーLocal-first and private

账户、余额、历史和设置保存在本机，无遥测、无广告、无开发者云服务器。密钥仅发送到所选 Provider 官方接口或明确配置的 GIS 地址。

アカウント、残高、履歴、設定はローカル。テレメトリ・広告・開発者クラウドなし。キーは選択した公式 API または指定 GIS にのみ送信。

Accounts, balances, history, and settings stay local, with no telemetry, ads, or developer cloud. Keys go only to selected official APIs or explicitly configured GIS endpoints.
