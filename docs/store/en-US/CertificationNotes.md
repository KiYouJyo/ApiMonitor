Certification notes

- No telemetry, no ads, no in-app purchases
- All credentials are stored only in the local Windows Credential Locker and sent only to the corresponding official endpoints
- The app does not require administrator privileges; the Store build runs under a standard user account
- Update checks are manual only; the Store build uses StoreContext and never downloads GitHub packages
- Accessibility: keyboard and Narrator support, complete trilingual resources, light / dark / high-contrast themes
- Screenshots and listing assets use test data and never contain real keys
