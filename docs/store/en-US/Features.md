Features

- Multi-account management: several accounts per provider with separate balance / quota / health views
- AI balance providers: DeepSeek, OpenRouter (standard API key and Management key), Moonshot / Kimi, SiliconFlow, xAI (Management API)
- Map/GIS health: AMap, Baidu Maps, Tencent Location, Tianditu, SuperMap iServer, generic OGC WMS/WMTS/WFS
- Auto-refresh and low-balance alerts (Windows notification center, off by default)
- Notification-area tray, close-to-tray, sign-in startup (off by default), single instance
- Floating balance window: a compact always-on-top widget for a chosen account
- Insights: local history trends, consumption estimates, CSV export
- Portable backup: non-sensitive data only, never contains any key
- App health checks: 21 read-only non-sensitive checks (channel, versions, identity, credential store, data files, notifications, tray, scheduler, and more)
- First-run guide: privacy, account setup, run options, and feature tour
- Trilingual UI and light / dark / system themes
