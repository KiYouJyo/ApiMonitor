Privacy summary

- No ApiMonitor developer account is required; API keys are stored only in Windows Credential Locker
- API keys are sent only to the official endpoints of the providers you choose (or self-hosted GIS addresses you configure)
- Balances, history, and settings stay on your device; no telemetry, no ads, no developer cloud servers
- Notifications are generated locally and stop when you exit the app
- GitHub and Store builds use different update checks, both triggered only when you click "Check for updates"
- Portable backups never contain keys; the Store build is a fresh install and does not migrate old sideload data
