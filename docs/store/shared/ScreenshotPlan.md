# Screenshot plan (v1.0.0)

Screenshots must be captured from the real v1.0.0 UI (Store-identity
acceptance build) using dedicated test accounts or safe mock data. Never
capture real API keys, Authorization headers, personal account names,
balances, local paths, or debug consoles.

Suggested screenshot set (1366×768 or larger, PNG, 16:9 or 4:3 as accepted by
the current Partner Center requirements):

| # | Subject | Content notes |
| --- | --- | --- |
| 1 | Home / account overview | Test accounts only; safe amounts |
| 2 | Insights page | Trend chart with mock/local test history |
| 3 | Multi-account list | Several test accounts, provider filters |
| 4 | Balance alert settings | Notification settings section |
| 5 | Floating balance window | Compact widget with a test account |
| 6 | About page | Version, channel, health checks sections |

Trilingual pages use the corresponding language UI (zh-CN / en-US / ja-JP)
or follow the current Partner Center screenshot language policy.
