主要功能

- 多账户管理：同一 Provider 多个账户，余额/额度/服务健康分开展示
- AI 余额 Provider：DeepSeek、OpenRouter（普通 API Key 与 Management Key）、Moonshot / Kimi、SiliconFlow、xAI（Management API）
- 地图/GIS 健康：高德、百度地图、腾讯位置服务、天地图、SuperMap iServer、通用 OGC WMS/WMTS/WFS
- 自动刷新与低余额提醒（Windows 通知中心，默认关闭）
- 通知区域托盘、关闭到托盘、登录启动（默认关闭）、单实例
- 悬浮余额窗：始终置顶的紧凑小窗，显示选定账户的核心额度
- 数据洞察：本机历史趋势、消耗估算、CSV 导出
- 便携备份：仅非敏感数据，不含任何密钥
- 应用运行状况检查：渠道、版本、身份、凭据存储、数据文件、通知、托盘、调度等 21 项
- 首次启动引导：隐私说明、添加账户、运行方式与功能入口
- 三语界面与浅色/深色/跟随系统主题
