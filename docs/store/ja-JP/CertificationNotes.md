認定メモ

- テレメトリなし、広告なし、アプリ内課金なし
- すべての資格情報はローカルの Windows Credential Locker にのみ保存され、対応する公式エンドポイントにのみ送信されます
- アプリは管理者権限を要求せず、Store 版は標準ユーザー権限で動作します
- 更新確認は手動のみです。Store 版は StoreContext を使用し、GitHub パッケージをダウンロードしません
- アクセシビリティ：キーボードと Narrator 対応、3 言語リソース完備、ライト / ダーク / ハイコントラスト対応
- スクリーンショットとストア素材はテスト データを使用し、実際の鍵を含みません
