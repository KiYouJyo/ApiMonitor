主な機能

- 複数アカウント管理：Provider ごとに複数アカウント、残高 / 枠 / 健全性を分けて表示
- AI 残高 Provider：DeepSeek、OpenRouter（通常 API キーと Management Key）、Moonshot / Kimi、SiliconFlow、xAI（Management API）
- 地図/GIS 健全性：高徳、百度地図、Tencent Location、天地図、SuperMap iServer、汎用 OGC WMS/WMTS/WFS
- 自動更新と残高通知（Windows 通知センター、既定オフ）
- 通知領域トレイ、トレイに閉じる、ログイン時起動（既定オフ）、単一インスタンス
- フローティング ウィンドウ：選択したアカウントの主要残高を常時表示
- データ洞察：ローカル履歴の推移、消費見積もり、CSV エクスポート
- 携帯バックアップ：非機密データのみ、鍵は一切含みません
- アプリ健全性チェック：チャネル、バージョン、ID、資格情報ストア、データ ファイル、通知、トレイ、スケジューラなど 21 項目
- 初回起動ガイド：プライバシー、アカウント追加、動作設定、機能紹介
- 3 言語 UI とライト / ダーク / システム追従テーマ
