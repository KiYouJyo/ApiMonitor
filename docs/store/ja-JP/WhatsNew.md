v1.0.0 の新機能

- Microsoft Store チャネル：公式 ID（JoKiy.ApiMonitor）とチャネル別の更新確認（Store 版は GitHub のダウンロード ページを開きません）
- 初回起動ガイド：プライバシー、アカウント追加、動作設定、機能紹介の 4 ステップ。スキップ可能、設定から再表示可能
- アプリ健全性チェック：非機密情報のみを読む 21 項目のチェック、診断情報のコピーとサポート文書への導線
- バージョンとチャネル情報の一元管理：バージョン、パッケージ バージョン、配布チャネル、パッケージ ID、アーキテクチャを表示
- Store 版は新規インストールとして開始：旧サイドロードのアカウント・履歴・設定・資格情報を移行しません
- 開発ビルドは「開発ビルド」と明示され、公式更新を主張しません
